1. 打开 Cloudflare 控制台（免费注册，无需银行卡）

2. 左侧 Workers & Pages → Create → Create Worker → 名字填 news-proxy → Deploy

3. 点 Edit code → 把仓库里 worker/news-proxy.js 全部内容粘贴进去 → Save and deploy

4. 复制地址栏的网址（形如 https://news-proxy.xxx.workers.dev）

5. 回到本应用 → 右上角 ⚙️ 设置 → 填入「新闻代理地址」→ 保存
