# 股市新闻追踪分析系统

一个纯前端的网页应用，可部署到 **GitHub Pages** 免费使用，支持浏览器直接访问。

## 功能特性

### 页面1：新闻追踪
- 字段展示：日期、新闻、概念分类、行业分类、自定义标记、关联股票、新闻当天股价、924股价（2024-09-24）、今日股价、今日涨跌幅、距今、距今幅度、924距今、分类标签、操作
- 导入新闻：支持粘贴导入（每行一条）
- 手动添加/编辑/删除新闻
- 支持按日期查找、关键词搜索、分类筛选
- 对「距今幅度」「距今」「今日涨跌幅」等多列排序
- 一键刷新所有关联股票的实时行情与历史价格
- 下拉分类：主线实体、个股实体、主线概念、个股概念、利空概念（可编辑）
- 反选/全选/批量删除

### 页面2：股票池管理
- 按日期创建股票池，批量输入股票代码
- 自动计算并排序不同日期的平均涨跌幅
- 点击进入股票池明细，展示：振幅、当日涨跌幅、资金流入、散户人数、净利润同比、营收同比、换手率
- 支持明细表按振幅/涨跌幅排序

### 页面3：热门板块
- 展示当日热门板块、热门股票
- 统计当日新闻涉及的概念频次，从多到少排序
- 选择日期加载当日股票，自动关联当日新闻
- 股票明细表可排序「振幅」「当日涨跌幅」

## 数据源

| 数据 | 来源 | 说明 |
|------|------|------|
| 实时股价、振幅、涨跌幅、换手率 | 腾讯股票接口（`qt.gtimg.cn`） | 支持 CORS，浏览器直接访问 |
| 历史价格（924、新闻日股价） | 腾讯历史K线（`web.ifzq.gtimg.cn`） | 不复权，取真实交易价格 |
| 资金流入、财务数据、散户人数 | 东方财富接口 | best-effort，部分网络环境可能受限；已做友好提示 |

## 快速部署到 GitHub Pages

### 方法A：直接上传文件（最简单）

1. 在 GitHub 创建新仓库，例如 `stock-news-tracker`
2. 把本目录下文件全部上传到仓库根目录：
   - `index.html`
   - `css/style.css`
   - `js/store.js`
   - `js/stock-api.js`
   - `js/app.js`
   - `.github/workflows/deploy.yml`（可选，见方法B）
3. 进入仓库 **Settings → Pages**
4. **Source** 选择 **Deploy from a branch**，分支选 `main`，文件夹选 `/`（根目录）
5. 保存后，等待 1 分钟左右，访问 `https://你的用户名.github.io/stock-news-tracker/`

### 方法B：使用 GitHub Actions 自动部署

已包含 `.github/workflows/deploy.yml`。只要推送到 `main` 分支，会自动部署到 GitHub Pages。

使用步骤：
1. 把仓库（含 `.github/workflows/deploy.yml`）推送到 GitHub
2. 进入 **Settings → Pages**
3. **Source** 选择 **GitHub Actions**
4. 推送代码后 Actions 会自动运行，部署成功后可在 Pages 页面看到访问链接

### 首次访问

打开页面后，浏览器会询问是否使用 `localStorage` 本地存储数据，请允许。所有数据均保存在当前浏览器，不会上传到任何服务器，保障隐私。

## 数据导入/导出

- 点击右上角 **⬇️ 导出** 按钮，可将当前所有数据（新闻、股票池、设置）导出为 JSON 备份
- 点击右上角 **⬆️ 导入** 按钮，选择 JSON 文件恢复数据
- 建议定期导出备份

## 使用技巧

- **关联股票格式**：`贵州茅台(600519)`、直接输入 `600519` 或 `sh600519`，多个股票用逗号或换行分隔
- **股票池代码**：每行一个代码，如 `600519` 或 `宁德时代(300750)`
- **分类标签**：可在「设置」中自由增删
- **格隆汇/同花顺新闻**：由于浏览器跨域限制，自动抓取受限，建议复制到「粘贴导入」中使用

## 技术栈

- Vue 3（CDN 全局构建版，无需构建步骤）
- 原生 CSS3
- 腾讯股票接口 / 东方财富接口
- 纯静态文件，GitHub Pages 直接托管

## 本地预览

```bash
python3 -m http.server 8099
# 浏览器打开 http://localhost:8099
```

> 注意：因为浏览器 CORS 策略，本地用 `file://` 直接打开 index.html 会导致 JS 加载失败，请通过 HTTP 服务器访问。
